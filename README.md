# Breatheasy

Home maintenance subscription SaaS for recurring air filter delivery and installation.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Vercel deployment

## Highlights
- SaaS-style acquisition funnel for a recurring home service business
- Three pricing tiers designed around subscription retention and service frequency
- Booking and intake flows for onboarding new customers
- API routes for handling application logic and lead capture
- Built as a modern subscription-first landing and conversion experience

## Local development
```bash
npm install
npm run dev
```

## Scripts
```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Product focus
Breatheasy is structured like a lightweight SaaS product, pairing subscription pricing with operational intake flows so a local service business can sell and manage recurring plans online.
